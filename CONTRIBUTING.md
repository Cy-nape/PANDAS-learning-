# Contributing to Pandas Learning Guide

We appreciate any help that makes this guide clearer, more comprehensive, or easier to use.

## How to contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. Create a **new branch** for your change:
   ```bash
   git checkout -b my-feature
   ```
4. Make your edits (add notebooks, improve markdown, fix bugs, etc.).
5. **Run the notebooks** to ensure they still execute without errors.
6. **Commit** your changes with a concise message:
   ```bash
   git add <files>
   git commit -m "Add <description>"
   ```
7. **Push** to your fork and open a **Pull Request**.

## Style guidelines

- Keep notebook cells short and focused.
- Use markdown cells for explanations, with headings (`#`, `##`, etc.).
- Add comments in code cells where the operation may be non‑obvious.
- Follow PEP‑8 for any `.py` helper scripts.

## Code of conduct

Please follow the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
